# HackaTruck MakerSpace

O [HackaTruck MakerSpace](https://hackatruck.com.br/o-projeto/) é um projeto de capacitação em tecnologia executado pelo Instituto de Pesquisas Eldorado. A proposta combina estudo e prática no desenvolvimento de soluções, com um laboratório móvel inspirado na cultura maker.

## Como funciona

A capacitação começa com uma etapa a distância, que apresenta fundamentos de programação. O projeto também oferece uma etapa presencial em seu laboratório móvel, com atividades práticas e desenvolvimento de soluções. A participação e a oferta das etapas dependem das turmas e instituições parceiras.

Neste repositório, registro meus estudos da etapa a distância, organizados por módulo e conteúdo. Cada exercício possui uma pasta com seu código, enunciado e instruções para execução.

## Linguagem

Os exercícios registrados até agora utilizam **Swift**, linguagem de programação usada no desenvolvimento de aplicações para plataformas Apple. Os códigos desta etapa são programas independentes de console e podem ser executados com Swift ou no SwiftFiddle.
