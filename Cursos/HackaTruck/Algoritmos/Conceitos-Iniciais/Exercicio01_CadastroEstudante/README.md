# Exercício 01 — Cadastro de estudante

## Enunciado

exercicio 1 - Meu primeiro cadastro em Swift
Imagine que você está criando um programa para cadastrar uma estudante do HackaTruck.

Sua missão é escrever um código que:
1. Crie uma constante chamada nome com seu nome.
2. Crie uma variável chamada idade com sua idade.
3. Crie uma constante chamada curso com o valor "HackaTruck".
4. Crie uma variável chamada concluiuCurso com o valor false.
5. Exiba todas essas informações no terminal usando print().

## Executar

Com Swift instalado, abra esta pasta e execute:

```bash
swift Exercicio01.swift
```

Também é possível executar o código no SwiftFiddle.
