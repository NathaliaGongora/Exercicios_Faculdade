# HackaTruck — Algoritmos: conceitos iniciais

Exercícios em Swift para praticar os conceitos iniciais da trilha de algoritmos do HackaTruck: variáveis e constantes, tipos de dados, atribuição, operações aritméticas, comparações e operadores lógicos.

## Exercícios

| Exercício | Tema | Prática |
|---|---|---|
| [01](Exercicio01.swift) | Cadastro de estudante | Constantes, variáveis e exibição |
| [02](Exercicio02.swift) | Matrícula | Atualização de variáveis |
| [03](Exercicio03.swift) | Estoque | Tipos explícitos e atualização |
| [04](Exercicio04.swift) | Recursos humanos | Cadastro e promoção |
| [05](Exercicio05.swift) | Compras de papelaria | Cálculos e comparações |
| [06](Exercicio06.swift) | Entrada em evento | Operadores lógicos e aritméticos |
| [07](Exercicio07.swift) | Bolsas de estudo | Média, frequência e elegibilidade |
| [08](Exercicio08.swift) | Consumo de energia | Conversão de unidades e cálculo de custo |
| [09](Exercicio09.swift) | Pedido de papelaria | Desconto, estoque e pagamento |
| [10](Exercicio10.swift) | Acompanhamento de curso | Média, frequência e condições |

Os exercícios 01 a 07 foram enviados por Nathália. Os exercícios 08 a 10 são exemplos complementares preparados com auxílio de IA para ampliar a prática; não são identificados como atividades oficiais do curso.

## Como executar

Cada arquivo é um programa independente. Com Swift instalado, execute no terminal, por exemplo:

```bash
swift Exercicio01.swift
```

Também é possível copiar o conteúdo de um arquivo por vez para o SwiftFiddle.
