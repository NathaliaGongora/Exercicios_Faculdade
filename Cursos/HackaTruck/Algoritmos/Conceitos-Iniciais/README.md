# Algoritmos — conceitos iniciais

## Executar

Com Swift instalado, abra esta pasta e execute o exercício desejado. Por exemplo:

```bash
swift Exercicio01_CadastroEstudante/Exercicio01.swift
```

Cada programa é independente. Você também pode copiar seu código para o SwiftFiddle.
