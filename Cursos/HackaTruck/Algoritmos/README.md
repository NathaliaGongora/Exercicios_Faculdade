# Primeiro módulo — Algoritmos

Este módulo reúne os estudos iniciais de algoritmos do HackaTruck. Os exercícios praticam a construção de programas em Swift e a organização de passos para resolver problemas.

## Conteúdos estudados

- Declaração e atribuição de variáveis e constantes.
- Tipos de dados como texto, números e valores booleanos.
- Operações aritméticas e conversão de tipos.
- Operadores de comparação e operadores lógicos.
- Exibição de informações com `print()` e interpolação de strings.

## Atividades

| Conteúdo | Exercícios |
|---|---|
| [Conceitos iniciais](Conceitos-Iniciais/README.md) | 10 exercícios de cadastro, cálculos e verificações |

Os exercícios 01 a 07 correspondem aos arquivos enviados; os exercícios 08 a 10 são práticas complementares. Outros conteúdos do módulo serão acrescentados conforme o avanço nos estudos.

## Como executar

Cada exercício é independente. Abra sua pasta para consultar o enunciado e as instruções. É possível executar os programas com Swift instalado ou copiar o código para o SwiftFiddle.
