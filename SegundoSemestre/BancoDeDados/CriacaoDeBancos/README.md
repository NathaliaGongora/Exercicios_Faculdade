# Criacao de Bancos de Dados

Lista com dez exercicios de criacao de bancos de dados no SQL Server.

O primeiro exercicio corresponde ao modelo oficial do consultorio medico. Os demais sao exercicios complementares do mesmo tipo e nivel.

| Exercicio | Banco | Descricao |
|---|---|---|
| [Exercicio 01](Exercicio01.sql) | Consultorio medico | Pacientes, exames, medicos, especialidades e consultas |
| [Exercicio 02](Exercicio02.sql) | Clinica veterinaria | Tutores, animais, veterinarios e atendimentos |
| [Exercicio 03](Exercicio03.sql) | Biblioteca | Alunos, livros, autores e emprestimos |
| [Exercicio 04](Exercicio04.sql) | Escola | Cursos, alunos, professores, disciplinas e matriculas |
| [Exercicio 05](Exercicio05.sql) | Loja | Clientes, produtos, pedidos e itens dos pedidos |
| [Exercicio 06](Exercicio06.sql) | Hotel | Hospedes, quartos e reservas |
| [Exercicio 07](Exercicio07.sql) | Oficina mecanica | Clientes, veiculos, mecanicos e ordens de servico |
| [Exercicio 08](Exercicio08.sql) | Academia | Alunos, planos, professores, aulas e inscricoes |
| [Exercicio 09](Exercicio09.sql) | Restaurante | Clientes, mesas, produtos, pedidos e itens |
| [Exercicio 10](Exercicio10.sql) | Sistema de eventos | Clientes, locais, eventos e inscricoes |

## Execucao

Cada arquivo cria um banco independente. Abra apenas o exercicio desejado no SQL Server Management Studio e execute todo o script.
