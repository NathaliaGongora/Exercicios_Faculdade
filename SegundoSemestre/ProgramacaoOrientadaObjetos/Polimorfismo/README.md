# Polimorfismo

Exercicios de Programacao Orientada a Objetos sobre polimorfismo dinamico por sobrescrita e polimorfismo estatico por sobrecarga.

Os tres primeiros codigos correspondem aos exercicios oficiais da AC2-L6 Parte 2. Os demais sao exercicios complementares sobre o mesmo conteudo.

| Exercicio | Tipo | Conteudo |
|---|---|---|
| [Exercicio 01](Exercicio01.java) | Dinamico e estatico | Animais, sobrescrita e sobrecarga em `Cobra` e `GoldFish` |
| [Exercicio 02](Exercicio02.java) | Dinamico | Formas geometricas e calculo de area |
| [Exercicio 03](Exercicio03.java) | Dinamico | Vencimentos de empregados |
| [Exercicio 04](Exercicio04.java) | Dinamico | Formas de pagamento |
| [Exercicio 05](Exercicio05.java) | Dinamico | Tipos de notificacao |
| [Exercicio 06](Exercicio06.java) | Dinamico | Calculo de bonus |
| [Exercicio 07](Exercicio07.java) | Dinamico | Aluguel de veiculos |
| [Exercicio 08](Exercicio08.java) | Dinamico | Taxas de contas bancarias |
| [Exercicio 09](Exercicio09.java) | Dinamico | Descontos de produtos |
| [Exercicio 10](Exercicio10.java) | Dinamico e estatico | Tipos de entrega e sobrecarga do frete |

## Observacao

O enunciado do exercicio 03 nao informa o adicional das horas extras. Foi utilizado o adicional de 50%, fazendo cada hora excedente valer 1.5 vez o valor da hora normal.
