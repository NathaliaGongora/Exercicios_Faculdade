# Encapsulamento com interfaces

Exercícios de Programação Orientada a Objetos sobre atributos privados, construtores, métodos `GET` e `SET`, interfaces e sobrescrita de métodos com `@Override`.

Os dois primeiros exercícios foram desenvolvidos a partir da atividade apresentada no final da aula. Como o terceiro enunciado ainda estava indefinido, os demais exercícios seguem o mesmo conteúdo e nível de dificuldade.

| Exercício | Conteúdo |
|---|---|
| [Exercício 01](Exercicio01.java) | Funcionário, cálculo de salário e holerite |
| [Exercício 02](Exercicio02.java) | Lutador, categoria e histórico de combates |
| [Exercício 03](Exercicio03.java) | Conta bancária, depósito e saque |
| [Exercício 04](Exercicio04.java) | Produto e controle de estoque |
| [Exercício 05](Exercicio05.java) | Aluno, média e situação final |
| [Exercício 06](Exercicio06.java) | Veículo, velocidade e estado ligado |
| [Exercício 07](Exercicio07.java) | Televisão, volume e canal |
| [Exercício 08](Exercicio08.java) | Reserva de hotel e desconto |
| [Exercício 09](Exercicio09.java) | Livro e controle de empréstimo |
| [Exercício 10](Exercicio10.java) | Pedido, subtotal, desconto e total |

## Conceitos praticados

- Encapsulamento com atributos privados
- Métodos acessores e modificadores
- Construtores
- Criação e implementação de interfaces
- Métodos abstratos
- Anotação `@Override`
- Validações dentro dos métodos
