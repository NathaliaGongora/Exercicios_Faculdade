# Materiais de apoio — Google Glass

Os arquivos `curso-html5-pacote01.zip` e `curso-html5-pacote02.zip`, fornecidos com as aulas, pertencem ao material didático do projeto Google Glass de Gustavo Guanabara.

- Pacote 01: textos-base, páginas para desenvolver, CSS, scripts, fontes, imagens e referências visuais.
- Pacote 02: arquivos de áudio e vídeo para os exemplos multimídia.

Esses pacotes são referências de terceiros, não uma atividade autoral concluída. As páginas-base ainda contêm instruções como “AQUI ENTRA UMA FOTO”. As duas imagens de lâmpada usadas na [prática de troca de imagem](../JavaScript/DOM/Exercicio10_TrocaDeImagem/README.md) vieram do pacote 01.

O restante dos pacotes não foi duplicado no repositório: os exercícios publicados usam somente os recursos de que precisam. Os textos do Google Glass descrevem o contexto de 2013, e não informações atuais do produto.
