## Como executar

No GitHub, os links para arquivos HTML exibem o código-fonte. Para executar, baixe ou clone o repositório e abra o HTML no navegador. Os scripts são simples arquivos locais e não exigem bibliotecas. Mantenha estilo.css, os scripts e a pasta Recursos ao lado das páginas.

## Observações

- Os exercícios de formulários deste conteúdo são demonstrações locais. Eles não enviam nem armazenam dados.
- Áudio e vídeo usam arquivos curtos de teste: um tom sem fala e uma tela azul sem áudio. Não há reprodução automática.
- O conteúdo editável não persiste após recarregar a página.
- O arrastar e soltar também pode ser feito com os botões, usando teclado.
- Os slides citam recursos antigos como keygen, command e input datetime. Os exemplos usam elementos disponíveis na especificação atual e datetime-local para data/hora local.
- As categorias de conteúdo HTML têm regras específicas de aninhamento; a divisão visual entre linha e bloco, isoladamente, não define todas as combinações permitidas.
