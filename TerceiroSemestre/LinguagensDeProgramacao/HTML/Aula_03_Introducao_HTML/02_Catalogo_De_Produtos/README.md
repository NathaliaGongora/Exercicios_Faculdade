# 02 — Catalogo De Produtos

**Origem:** Lista do professor.

## Enunciado

Exercicio 02 - Catálogo de Produtos
Origem: Lista HTML — exercício 2

Crie o catálogo da lista: título H1, tabela com foto, código, descrição, quantidade em estoque
e valor unitário; seção Descrição H2; Características do Produto H3; Especificações; lista não
ordenada; Avaliação do produto H3 e lista de definição com José Aparecido (Muito bom) e Joaquim
Jorge (Bom).

Dados da tabela:
1 - Mouse Laser com fio Dell - estoque 5 - R$ 179,00.
2 - Mouse Bluetooth Dell - estoque 6 - R$ 338,00.
3 - Mouse óptico usb preto 100 - estoque 3 - R$ 48,30.
Características: sensor óptico de 1.600 DPI; cabo USB de 1,5m; design ambidestro;
três botões integrados; compatibilidade com Windows e Mac.
Avaliações: José Aparecido - Muito bom; Joaquim Jorge - Bom.
