# 09 — Formulario De Cadastro

**Origem:** Prática complementar.

## Enunciado

Exercicio 09 - Formulário de cadastro
Origem: Complementar — formulários

Crie um formulário com nome, email, senha, seleção de curso, turno usando radio, aceite de
termos usando checkbox, textarea para observações e botões de envio e limpeza. Associe os
labels aos campos.
