## Observações

- As três imagens dos mouses foram extraídas do documento da lista. São recursos usados nas atividades 2 e 5.
- A lista cita outro conjunto de slides de marcação de texto (“3- 02 HTML 5”), que não foi anexado. O exercício 1 foi resolvido pela imagem presente no próprio documento.
- Em “Especificações”, o texto da lista indica label. Na página, esse texto usa um parágrafo: label identifica controles de formulário e é praticado nos exercícios 9 e 10.
- As âncoras usam o atributo id para identificar o destino.
- As tabelas têm somente regras CSS simples para mostrar bordas e espaçamento. O objetivo é praticar a estrutura HTML.
- Os títulos seguem a hierarquia do conteúdo. Não há um limite geral de duas seções h2 por página.
- Os formulários são exemplos de campos, sem servidor e sem persistência. A senha de demonstração não tem name, para não entrar nos parâmetros do envio local do exemplo.
