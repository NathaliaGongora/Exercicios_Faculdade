# HTML — atividades das aulas

Estudos de HTML da disciplina Linguagens de Programação, no terceiro semestre.
As pastas seguem a numeração dos materiais da disciplina. Cada aula contém
seu objetivo, a lista de atividades e as instruções para visualizar as páginas.

## Navegação

| Aula | Conteúdo | Atividades |
|---|---|---|
| [03 — Introdução ao HTML](Aula03-IntroducaoHTML/README.md) | Textos, links, imagens, tabelas e listas | 2 da lista, 4 dos slides e 4 complementares |
| [04 — HTML5](Aula04-HTML5/README.md) | Semântica, campos, validação e recursos de mídia | 10 práticas complementares aos slides |
| [05 — Formulários](Aula05-Formularios/README.md) | Controles de formulário e inscrição em cursos | 1 da lista e 9 complementares |

## Como consultar

1. Escolha uma aula na tabela.
2. Consulte o README da aula para identificar o enunciado e a origem da atividade.
3. Abra o arquivo indicado. Os enunciados também estão nos comentários iniciais dos arquivos HTML.

Os links do GitHub mostram o código-fonte. Para visualizar as páginas funcionando,
baixe ou clone o repositório e abra os arquivos HTML no navegador, mantendo os
arquivos de apoio nos mesmos locais.

A atividade [Cursos e inscrição](Aula05-Formularios/01-CursosEInscricao/README.md)
reúne suas duas páginas e o JavaScript em uma pasta própria. Seu README explica
o fluxo e a configuração da API.

Cada aula reúne dez atividades. As práticas complementares estão identificadas
separadamente das propostas do professor.
