# 10 — Arquivo E Controles

**Origem:** Prática complementar.

## Enunciado

Exercicio 10 - Seleção de arquivo e controles
Origem: Complementar — arquivo, hidden e controles

Crie um formulário de demonstração com campo de arquivo, campo oculto de identificação, lista
de categorias, textarea e botões. O exemplo deve permitir escolher e limpar o arquivo sem
enviar dados a um serviço.
