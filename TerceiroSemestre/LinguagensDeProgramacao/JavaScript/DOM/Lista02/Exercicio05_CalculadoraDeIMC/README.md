# Exercício 05 — Calculadora De IMC

**Origem:** Lista 02 do professor.

## Enunciado

Enunciado:
Crie uma página com dois campos (peso e altura) e um botão "Calcular IMC". Ao clicar, exiba em uma <div>:
O valor do IMC (peso / altura²)
A classificação:
IMC < 18,5 → "Abaixo do peso"
18,5 ≤ IMC < 25 → "Peso normal"
25 ≤ IMC < 30 → "Sobrepeso"
IMC ≥ 30 → "Obesidade"
Valide se os dois campos foram preenchidos; caso contrário, exiba alert("Preencha todos os campos!").

## Executar

Abra [index.html](index.html) no navegador após baixar ou clonar a pasta. Mantenha `script.js`, `estilo.css` e eventuais imagens junto da página. No GitHub, os links mostram o código-fonte.

Exercício de programação com a fórmula e as faixas fornecidas na lista. A classificação usa o valor calculado antes do arredondamento da exibição.
