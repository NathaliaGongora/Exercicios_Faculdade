# Exercício 06 — Validacao De Senha

**Origem:** Lista 02 do professor.

## Enunciado

Enunciado:
Crie um campo de senha (type="password") que, enquanto o usuário digita, mostre uma mensagem abaixo indicando se a senha atende aos requisitos:
Mínimo 8 caracteres
Pelo menos 1 número
A mensagem deve ficar vermelha quando houver erro e verde quando estiver tudo certo. Use o evento input (ou oninput).

## Executar

Abra [index.html](index.html) no navegador após baixar ou clonar a pasta. Mantenha `script.js`, `estilo.css` e eventuais imagens junto da página. No GitHub, os links mostram o código-fonte.

A verificação aplica somente as duas regras da lista. A senha não é enviada nem armazenada.
