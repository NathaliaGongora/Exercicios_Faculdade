# Manipulação do DOM

Exercícios de JavaScript executados no navegador, organizados pelas listas da disciplina.

| Lista | Conteúdo | Origem |
|---|---|---|
| [Lista 01](Lista01/README.md) | Cores, tarefas, contador, calculadora e interação com a página | 5 atividades da lista e 5 complementares |
| [Lista 02](Lista02/README.md) | Navegador, remoção de tarefas, IMC, senha, filtro, galeria, abas e carrinho | 10 atividades da lista do professor |

Cada exercício fica em sua própria pasta, no padrão `Exercicio01_NomeDoTema`. Consulte o README da lista e depois o da atividade. Para executar, abra `index.html` no navegador, preservando os arquivos de apoio.
