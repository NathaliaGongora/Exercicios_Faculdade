Para Fundamentos e Arrow Functions, com o Node.js instalado, abra a pasta JavaScript no VS Code e execute no terminal:

```bash
node Fundamentos/Exercicio01_QuatroOperacoes/script.js
```

As atividades de DOM usam páginas HTML: siga o README de DOM.
