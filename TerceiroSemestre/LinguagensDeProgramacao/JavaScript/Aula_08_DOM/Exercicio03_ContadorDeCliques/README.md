# Exercício 03 — Contador De Cliques

**Origem:** Lista do professor.

## Enunciado

Crie uma página HTML com um botão e um contador. Quando o botão é clicado, o contador deve ser incrementado em 1 e o valor atualizado na página.

## Executar

Abra [index.html](index.html) no navegador depois de baixar ou clonar a pasta. No GitHub, o link mostra o código-fonte.
