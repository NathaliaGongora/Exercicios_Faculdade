# Exercício 01 — Cor Aleatoria

**Origem:** Lista do professor.

## Enunciado

Crie uma página HTML com um botão e uma <div>. Quando o botão é clicado, a cor de fundo da <div> deve mudar para uma cor aleatória. Use um array com cinco cores, Math.random e Math.floor.

## Executar

Abra [index.html](index.html) no navegador depois de baixar ou clonar a pasta. No GitHub, o link mostra o código-fonte.
