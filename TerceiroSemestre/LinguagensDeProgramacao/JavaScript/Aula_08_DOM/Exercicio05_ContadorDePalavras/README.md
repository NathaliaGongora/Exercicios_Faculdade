# Exercício 05 — Contador De Palavras

**Origem:** Lista do professor.

## Enunciado

Crie uma página HTML que conte o número de palavras em uma frase ou parágrafo inserido pelo usuário. Exiba o resultado na página.

## Executar

Abra [index.html](index.html) no navegador depois de baixar ou clonar a pasta. No GitHub, o link mostra o código-fonte.

A contagem considera grupos de caracteres separados por espaços, tabulações ou quebras de linha.
