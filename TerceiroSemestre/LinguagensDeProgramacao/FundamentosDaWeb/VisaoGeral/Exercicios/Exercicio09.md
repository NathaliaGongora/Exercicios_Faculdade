# Exercício 09 — HTML CSS e JavaScript

## Enunciado

Qual é a função de HTML, CSS e JavaScript em uma página?

## Resposta

HTML descreve a estrutura e o significado do conteúdo. CSS define a apresentação visual. JavaScript permite executar lógica e adicionar comportamento à página. JavaScript também pode executar no servidor usando um ambiente como Node.js.
