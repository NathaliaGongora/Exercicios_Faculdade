# Exercício 10 — Web services e REST

## Enunciado

Para que serve um web service e como uma API REST pode organizar seus recursos?

## Resposta

Um web service permite a comunicação entre sistemas pela rede. Em uma API que segue convenções REST, recursos podem ser identificados por URLs e operados por métodos HTTP. JSON é um formato comum de dados, mas não é obrigatório para REST. Exemplo: GET /clientes/36 consulta um cliente e DELETE /clientes/36 solicita sua exclusão. SOAP é um protocolo de mensagens; REST é um estilo arquitetural.
