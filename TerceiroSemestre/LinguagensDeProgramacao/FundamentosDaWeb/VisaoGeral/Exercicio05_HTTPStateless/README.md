# Exercício 05 — HTTP stateless

## Enunciado

O que significa dizer que HTTP é stateless?

## Resposta

Cada requisição é tratada sem depender de um estado de conversa mantido pelo próprio protocolo entre requisições. Uma aplicação pode manter sessões usando mecanismos como cookies e armazenamento no servidor.
