# Exercício 02 — Cliente e servidor

## Enunciado

Qual é o papel do cliente e do servidor em uma aplicação web?

## Resposta

O cliente solicita recursos e apresenta a interface ao usuário. O servidor recebe requisições, executa as operações necessárias e devolve respostas. Um navegador é um exemplo de cliente.
