# Exercício 06 — Métodos HTTP

## Enunciado

Associe GET, POST, PUT e DELETE às operações de uma API de clientes.

## Resposta

GET /clientes consulta a coleção de clientes. GET /clientes/36 consulta o cliente 36. POST /clientes solicita a criação de um cliente. PUT /clientes/12 substitui a representação do cliente 12 conforme o contrato da API. DELETE /clientes/41 solicita a exclusão do cliente 41.
