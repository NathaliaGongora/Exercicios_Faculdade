# Exercício 04 — Requisição e resposta

## Enunciado

Descreva o fluxo básico de acesso a uma página web.

## Resposta

O usuário informa uma URL. O navegador envia uma requisição HTTP ao servidor. O servidor devolve uma resposta com status, cabeçalhos e, quando aplicável, conteúdo. O navegador interpreta os recursos recebidos e apresenta a página.
