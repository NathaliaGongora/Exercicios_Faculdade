# Exercício 08 — Client-side e server-side

## Enunciado

Qual é a diferença entre processamento no cliente e no servidor?

## Resposta

Client-side executa no ambiente do cliente, por exemplo, um JavaScript que altera a página no navegador. Server-side executa no servidor, por exemplo, a consulta ao banco e a validação de uma operação. A validação no navegador não substitui a validação no servidor.
