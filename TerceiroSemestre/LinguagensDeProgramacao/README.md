# Linguagens de Programação — 3º semestre

Material de desenvolvimento web organizado por linguagem e conteúdo. Cada área tem um índice com os conteúdos e as atividades. Cada exercício fica em uma pasta própria com nome no padrão `Exercicio01_NomeDoTema`, enunciado e instruções de execução.

| Área | Conteúdo disponível |
|---|---|
| [Fundamentos da Web](FundamentosDaWeb/README.md) | Visão geral, cliente/servidor, HTTP e web services |
| [HTML](HTML/README.md) | Aulas 03 a 06: introdução, HTML5, formulários e containers |
| [CSS](CSS/README.md) | Fundamentos de CSS, layout e Flexbox |
| [JavaScript](JavaScript/README.md) | Fundamentos, arrow functions e manipulação do DOM |

Exemplo de caminho: **JavaScript → ArrowFunctions → Exercicio01_ClassificarTriangulos → script.js**.

Cada conteúdo reúne dez exercícios, com os complementares identificados quando necessário. Os arquivos de código começam com o enunciado em comentário.
