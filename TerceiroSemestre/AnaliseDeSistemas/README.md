# Análise de Sistemas — 3º semestre

Material de estudo de UML e engenharia de requisitos. Os diagramas das aulas são feitos manualmente no **Lucidchart** e guardados como imagens.

## Conteúdos

| Tipo de conteúdo | O que representa |
|---|---|
| [Casos de uso](CasosDeUso/README.md) | Atores e objetivos do sistema |

| [Sequência](DiagramasDeSequencia/README.md) | Ordem das mensagens em um cenário |

## Organização

Escolha o tipo de diagrama e depois o problema. Por exemplo: **Sequência → Lumio**. Dentro de cada problema ficam a imagem e uma explicação curta. O resumo da aula fica separado dos exemplos.

O **Lumio** é o projeto principal. Campeonato de skate, cadastro e autenticação, biblioteca e loja virtual são exemplos complementares para praticar, mantendo cinco problemas por tipo de diagrama.

## Sobre as imagens

Cada pasta reúne a imagem do diagrama e a descrição do problema. Os originais das atividades e os modelos complementares de estudo estão identificados para acompanhar a evolução da modelagem. As imagens exportadas podem ser consultadas diretamente no GitHub.
