# Diagramas de Componentes

O diagrama de componentes apresenta a organização de um sistema em partes autônomas e suas dependências. A aula aborda componentes, interfaces fornecidas e requeridas, portas, dependências, classes internas e nós de execução.

## O que foi visto

- Um componente encapsula uma parte do sistema e pode disponibilizar ou exigir interfaces por meio de portas.
- Estereótipos ajudam a identificar artefatos como executáveis, bibliotecas, tabelas, documentos e arquivos.
- Componentes internos podem ser mostrados em caixa branca; uma caixa preta enfatiza apenas as interfaces externas.
- Dependências mostram que um componente utiliza serviços de outro.
- Nós representam recursos de execução, como servidores e dispositivos; podem conter componentes e artefatos.
