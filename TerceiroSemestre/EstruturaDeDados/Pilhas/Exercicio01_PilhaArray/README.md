# Exercicio 01 — PilhaArray

**Origem:** Lista do professor.

## Enunciado

Implemente uma pilha generica com Object[], topo inicial -1, capacidade fixa, estaVazia, estaCheia, empilhar, desempilhar, topo, tamanho e exibirPilha. Crie um menu Scanner e trate pilha cheia e vazia.

## Arquivos e execucao

- [PilhaArray.java](PilhaArray.java)
- [Entrada.java](Entrada.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida PilhaArray.java Entrada.java
java -cp saida PilhaArray
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
