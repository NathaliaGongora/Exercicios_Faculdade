# Exercicio 04 — OrdenarPilha

**Origem:** Lista do professor.

## Enunciado

Leia a quantidade e os inteiros com Scanner. Ordene usando somente operacoes de pilha e pilha auxiliar, sem sort, vetores ou listas para ordenar. Ao desempilhar o resultado, os menores devem sair primeiro.

## Arquivos e execucao

- [Exercicio4Ordenacao.java](Exercicio4Ordenacao.java)
- [Entrada.java](Entrada.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida Exercicio4Ordenacao.java Entrada.java
java -cp saida Exercicio4Ordenacao
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
