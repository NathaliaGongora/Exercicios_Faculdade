# Exercicio 03 — Palindromo

**Origem:** Lista do professor.

## Enunciado

Leia um texto, remova espacos e diferencie apenas o conteudo em minusculas. Compare a verificacao de palindromo usando PilhaArray, PilhaArrayList e java.util.Stack. Remova apenas os espacos e diferencas entre maiusculas e minusculas, conforme a lista.

## Arquivos e execucao

- [Exercicio3Palindromo.java](Exercicio3Palindromo.java)
- [Entrada.java](Entrada.java)
- [PilhaArray.java](PilhaArray.java)
- [PilhaArrayList.java](PilhaArrayList.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida Exercicio3Palindromo.java Entrada.java PilhaArray.java PilhaArrayList.java
java -cp saida Exercicio3Palindromo
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
