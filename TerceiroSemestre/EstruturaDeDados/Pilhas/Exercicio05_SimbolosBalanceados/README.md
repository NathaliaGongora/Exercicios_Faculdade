# Exercicio 05 — SimbolosBalanceados

**Origem:** Lista do professor.

## Enunciado

Leia uma expressao e valide parenteses, colchetes e chaves com uma pilha. Trate fechamento sem abertura, simbolo diferente do esperado e abertura sem fechamento. Ignore os demais caracteres.

## Arquivos e execucao

- [Exercicio5Balanceamento.java](Exercicio5Balanceamento.java)
- [Entrada.java](Entrada.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida Exercicio5Balanceamento.java Entrada.java
java -cp saida Exercicio5Balanceamento
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
