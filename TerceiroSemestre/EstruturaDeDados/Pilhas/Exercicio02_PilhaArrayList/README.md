# Exercicio 02 — PilhaArrayList

**Origem:** Referencia de sala indicada na lista.

## Enunciado

Implemente a pilha generica com ArrayList usada como referencia em sala, com menu Scanner, empilhar, desempilhar, topo, tamanho, estaVazia e exibirPilha. Remova pelo ultimo indice para preservar LIFO.

## Arquivos e execucao

- [PilhaArrayList.java](PilhaArrayList.java)
- [Entrada.java](Entrada.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida PilhaArrayList.java Entrada.java
java -cp saida PilhaArrayList
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
