# Exercicio 01 — Busca e Profundidade

**Origem:** Exercicio 1 dos slides.

## Enunciado

Crie uma arvore binaria de busca de inteiros, com menores a esquerda e maiores a direita. Implemente busca que retorna a profundidade ou -1, e percurso imprimindo valor e profundidade de cada no.

## Arquivos e execucao

- [Main.java](Main.java)
- [Entrada.java](Entrada.java)
- [ArvoreBinaria.java](ArvoreBinaria.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida Main.java Entrada.java ArvoreBinaria.java
java -cp saida Main
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.

A raiz tem profundidade zero. Valores repetidos sao ignorados para preservar menores e maiores estritos.
