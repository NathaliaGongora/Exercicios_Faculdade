# Exercicio 01 — PlaylistCircular

**Origem:** Lista do professor.

## Enunciado

Implemente no unico arquivo SpotifyPlaylist.java as classes Musica, PlaylistCircular e SpotifyPlaylist dos slides. Cadastre as tres musicas do exemplo, imprima titulos e artistas, avance ate retornar ao inicio e volte da primeira para a ultima. Preserve encadeamento duplo e circular.

## Arquivos e execucao

- [SpotifyPlaylist.java](SpotifyPlaylist.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida SpotifyPlaylist.java
java -cp saida SpotifyPlaylist
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.

Exemplo dos slides, com protecao para navegacao na playlist vazia. Nao integra nem controla o servico Spotify.
