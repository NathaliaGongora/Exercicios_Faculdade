# Exercicio 10 — Esvaziar e Reutilizar

**Origem:** Pratica complementar.

## Enunciado

Remova todas as etapas, tente navegar na estrutura vazia e adicione uma nova etapa.

## Arquivos e execucao

- [Main.java](Main.java)
- [Entrada.java](Entrada.java)
- [EtapaPipeline.java](EtapaPipeline.java)
- [PipelineCircular.java](PipelineCircular.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida Main.java Entrada.java EtapaPipeline.java PipelineCircular.java
java -cp saida Main
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
