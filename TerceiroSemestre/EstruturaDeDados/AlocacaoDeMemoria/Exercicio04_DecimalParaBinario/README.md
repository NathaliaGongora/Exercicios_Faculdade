# Exercicio 04 — DecimalParaBinario

**Origem:** Lista do professor.

## Enunciado

Leia um inteiro entre 0 e 255. Retorne um vetor de oito bits, preenchido do fim para o inicio com % 2 e / 2. Imprima os oito bits.

## Arquivos e execucao

- [Main.java](Main.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida Main.java
java -cp saida Main
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
