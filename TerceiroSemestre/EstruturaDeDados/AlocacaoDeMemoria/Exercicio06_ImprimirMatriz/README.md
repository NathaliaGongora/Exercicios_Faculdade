# Exercicio 06 — ImprimirMatriz

**Origem:** Lista do professor.

## Enunciado

Leia as dimensoes e os textos de uma matriz String. Imprima seus elementos com dois lacos for, separadores | e tabulacao. O metodo deve aceitar diferentes dimensoes.

## Arquivos e execucao

- [Main.java](Main.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida Main.java
java -cp saida Main
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.

A leitura interativa limita cada dimensao a 20 para manter a demonstracao pequena; o metodo de impressao percorre o tamanho recebido.
