# Exercicio 07 — MatrizTransposta

**Origem:** Lista do professor.

## Enunciado

Leia uma matriz de inteiros 3 x 2 e retorne sua transposta 2 x 3. Use transposta[coluna][linha] = original[linha][coluna] e imprima ambas com um metodo.

## Arquivos e execucao

- [Main.java](Main.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida Main.java
java -cp saida Main
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
