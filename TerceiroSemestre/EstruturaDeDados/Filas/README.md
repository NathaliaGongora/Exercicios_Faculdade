## Execucao e evidencias

Compile apenas uma pasta de exercicio por vez, seguindo seu README. A pasta `saida` e gerada localmente pelo javac e nao precisa ir para o repositorio. Os registros `Execucao.txt` mostram entradas usadas nos testes e saidas reais dos programas; nao substituem os prints da IDE solicitados pelo professor. Para a entrega no Canvas, execute no seu computador e capture os prints com entradas e resultados visiveis.
