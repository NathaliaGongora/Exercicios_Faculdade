# Exercicio 02 — FilaPrioridade

**Origem:** Lista do professor.

## Enunciado

Implemente FilaPrioridade com ArrayList<Integer>. Insira cada numero em ordem crescente, com menores no inicio; remova pelo indice zero. Crie menu Scanner, aceite repetidos e negativos e trate fila vazia.

## Arquivos e execucao

- [FilaPrioridade.java](FilaPrioridade.java)
- [Entrada.java](Entrada.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida FilaPrioridade.java Entrada.java
java -cp saida main.FilaPrioridade
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
