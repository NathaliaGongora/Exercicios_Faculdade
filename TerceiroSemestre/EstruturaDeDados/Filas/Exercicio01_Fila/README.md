# Exercicio 01 — Fila

**Origem:** Lista do professor.

## Enunciado

Implemente Fila<T> com ArrayList, estaVazia, enfileirar, desenfileirar, frente, tamanho e exibirFila. Crie menu Scanner 1 a 5 e 0 sair. Remova indice zero e trate fila vazia sem informar remocao de null.

## Arquivos e execucao

- [Fila.java](Fila.java)
- [Entrada.java](Entrada.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida Fila.java Entrada.java
java -cp saida main.Fila
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
