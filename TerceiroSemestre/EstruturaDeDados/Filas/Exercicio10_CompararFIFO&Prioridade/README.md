# Exercicio 10 — CompararFIFO e Prioridade

**Origem:** Pratica complementar.

## Enunciado

Leia cinco numeros, adicione-os numa fila comum e numa fila de prioridade e compare a ordem de remocao.

## Arquivos e execucao

- [Main.java](Main.java)
- [Entrada.java](Entrada.java)
- [Fila.java](Fila.java)
- [FilaPrioridade.java](FilaPrioridade.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida Main.java Entrada.java Fila.java FilaPrioridade.java
java -cp saida Main
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
