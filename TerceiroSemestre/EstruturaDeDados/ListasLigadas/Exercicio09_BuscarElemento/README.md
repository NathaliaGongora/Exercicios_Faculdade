# Exercicio 09 — BuscarElemento

**Origem:** Pratica complementar.

## Enunciado

Percorra uma lista por indice e descubra a primeira posicao de um valor informado. Retorne -1 quando nao existir.

## Arquivos e execucao

- [Main.java](Main.java)
- [Entrada.java](Entrada.java)
- [No.java](No.java)
- [ListaLigada.java](ListaLigada.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida Main.java Entrada.java No.java ListaLigada.java
java -cp saida Main
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
