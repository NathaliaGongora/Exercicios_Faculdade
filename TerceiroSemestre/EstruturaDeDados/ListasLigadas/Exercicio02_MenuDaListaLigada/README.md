# Exercicio 02 — MenuDaListaLigada

**Origem:** Lista do professor.

## Enunciado

Complete a lista ligada com menu Scanner e switch de 0 a 7: adicionar no final, inicio e posicao; remover do inicio, final e posicao; exibir lista e tamanho; sair. Leia o primeiro valor e preserve package Lista. Valide entradas nao numericas, indices e reinsercao apos esvaziar. Nao utilize ArrayList ou LinkedList.

## Arquivos e execucao

- [No.java](No.java)
- [ListaLigada.java](ListaLigada.java)
- [Entrada.java](Entrada.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida No.java ListaLigada.java Entrada.java
java -cp saida Lista.ListaLigada
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.

O pacote Lista usa L maiusculo conforme o enunciado. As operacoes foram implementadas a partir dos requisitos enviados; os arquivos Java originais iniciados em sala nao vieram anexados.
