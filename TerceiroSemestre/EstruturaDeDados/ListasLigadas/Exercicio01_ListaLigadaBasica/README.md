# Exercicio 01 — ListaLigadaBasica

**Origem:** Lista do professor.

## Enunciado

Implemente No.java com Object info, No proximoNo, construtor e getters/setters. Em ListaLigada.java, mantenha primeiroNo, ultimoNo e quantidadeNos; crie construtor com primeiro elemento, adicionar ao final, tamanhoLista e imprimirLista. O main deve criar A, B e C e imprimir A -> B -> C -> NULL. Extra opcional: estaVazio e construtor vazio.

## Arquivos e execucao

- [No.java](No.java)
- [ListaLigada.java](ListaLigada.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida No.java ListaLigada.java
java -cp saida ListaLigada
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
