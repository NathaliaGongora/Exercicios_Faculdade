# Exercicio 01 — DecimalParaBinario

**Origem:** Lista do professor.

## Enunciado

Leia um inteiro nao negativo com Scanner, valide a entrada e converta-o em String binaria por recursao, com caso-base para 0 e 1.

## Arquivos e execucao

- [exe1Recursao.java](exe1Recursao.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida exe1Recursao.java
java -cp saida exe1Recursao
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
