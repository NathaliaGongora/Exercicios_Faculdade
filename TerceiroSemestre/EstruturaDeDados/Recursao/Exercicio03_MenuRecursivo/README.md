# Exercicio 03 — MenuRecursivo

**Origem:** Lista do professor.

## Enunciado

Crie um menu com Scanner: 1 fatorial, 2 potencia, 3 decimal para binario e 4 sair. Mantenha o menu ate a opcao 4; trate entradas nao numericas, negativos e opcao inexistente. Os tres calculos devem ser recursivos.

## Arquivos e execucao

- [MenuRecursao.java](MenuRecursao.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida MenuRecursao.java
java -cp saida MenuRecursao
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
