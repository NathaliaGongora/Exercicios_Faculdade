# Exercicio 02 — PotenciaRecursiva

**Origem:** Lista do professor.

## Enunciado

Leia base e expoente inteiros com Scanner. Rejeite expoente negativo. Implemente calcularPotencia com caso-base expoente zero, chamada com expoente - 1 e retorno long. Nao use Math.pow nem lacos no calculo.

## Arquivos e execucao

- [exe2Recursao.java](exe2Recursao.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida exe2Recursao.java
java -cp saida exe2Recursao
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
