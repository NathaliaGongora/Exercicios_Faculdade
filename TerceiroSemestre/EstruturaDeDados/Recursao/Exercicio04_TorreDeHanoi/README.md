# Exercicio 04 — TorreDeHanoi

**Origem:** Lista do professor.

## Enunciado

Resolva Hanoi por recursao usando Scanner e matriz int[n][3]. A e a origem, B o destino e C a auxiliar. Exiba o estado inicial e apos cada movimento, respeite o topo e nunca coloque disco maior sobre menor. Mostre o total 2^n - 1.

## Arquivos e execucao

- [TorreDeHanoi.java](TorreDeHanoi.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida TorreDeHanoi.java
java -cp saida TorreDeHanoi
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.

A interface limita a 10 discos para evitar uma saida exponencial muito extensa. Teste tambem 1, 2, 0, -2 e texto.
