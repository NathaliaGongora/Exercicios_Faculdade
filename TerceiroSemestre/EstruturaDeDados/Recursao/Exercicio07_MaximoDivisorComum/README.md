# Exercicio 07 — MaximoDivisorComum

**Origem:** Pratica complementar.

## Enunciado

Leia dois inteiros entre 1 e 100000 e calcule o MDC pelo algoritmo recursivo de Euclides.

## Arquivos e execucao

- [Main.java](Main.java)

Execute os comandos dentro desta pasta, com o JDK instalado:

```bash
javac -encoding UTF-8 -d saida Main.java
java -cp saida Main
```

Cada pasta e um programa independente. Nao compile pastas diferentes juntas: algumas classes possuem o mesmo nome.
